API Connections

Update the credentials the platform uses to reach its model vendors and outbound integrations. Keys are applied to the running service immediately — the Virtuoso dispatcher and every adapter resolve credentials lazily, so the next call uses what you set here.

Durability note: instances are ephemeral. A key set on this page lives until the instance recycles. For permanent configuration, store it in Secret Manager and redeploy (see docs/PRODUCTION_SECRETS_SETUP.md). Values are never displayed back — status shows the last 4 characters only.
